# 私有资料与版权说明

本目录用于用户本人跨设备继续开发，包含其自行提供或本机已有的资料。

## 使用边界

- 原书 PDF 仅用于本人阅读、检索、页码定位和方法研究。
- 不在对外 Skill、公开仓库、销售包或群发资料中附带原书 PDF。
- 不长篇复制书中原文；Skill 中保留的是方法索引、释义和应用流程。
- 用户商业认知资料可能包含个人方法、业务信息或历史上下文，对外分享前必须人工检查。
- 飞书链接仅是来源索引；如需离线快照，应由用户在有权限的环境中另行导出。

## 对外分享建议

对外只发送 `05-portable-release` 中的便携包，并运行该包自己的 `verify_package.py`。不要直接转发本完整开发包。
