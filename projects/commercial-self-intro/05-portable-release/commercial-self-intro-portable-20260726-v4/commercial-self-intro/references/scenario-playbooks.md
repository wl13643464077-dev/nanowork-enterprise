# 场景适配与技术路由

平台字段和字符限制会变化，当前规则以界面和官方来源为准。以下是表达结构，不是平台硬性上限。所有口播用 `scripts/check_intro_length.py` 估算并以真人录音复核。

## 1. 抖音、视频号与短视频

- 默认技术：`F02 F04 D02 D04 D08 D10 D18 D24 E05 E09 E10 L01 L07 L10 L11`。
- 默认交付：账号定位句、主页简介、3秒开头、15秒置顶、30秒口播、字幕分行、单变量A/B开头。
- 抖音：价值和相关性前置，第一句直接进入问题、结果或反常识；不要用完整履历热身。
- 视频号：保留结果导向，增加一条真实经历、机制或服务场景，CTA可转向回复问题或看案例。
- 交付提示：标出停顿、重音、镜头目光和冷场恢复问句。
- 成长指标：前3秒留存、完播、主页访问、私信；每轮只改开头、证明或CTA之一。

## 2. 自媒体主页、公众号、小红书与LinkedIn

- 默认技术：`F01 F07 F17 D03 D04 D06 D08 D12 D13 D24 L02 L10 L11 L12`。
- 默认交付：搜索友好标题、40-80字短简介、120-200字标准简介、300-500字About、三个内容支柱。
- 写法：跨平台保持同一核心定位，但按平台改语气、证据和行动；用作品、案例和连续内容证明定位。
- 禁忌：堆“资深、赋能、生态、专家”；公开客户名、排名、数据前必须核验。
- 成长指标：搜索后的标签复述、主页到私信/链接点击转化、内容支柱与定位的一致率。

## 3. 商务社交、饭局、展会与客户初见

- 默认技术：`F02 F06 D02 D03 D04 D15 D18 D21 D24 E01 E04 E05 E07 E08 L05 L07 L08 L12`。
- 默认交付：18秒版、30秒电梯版、60秒展开版、三个追问分支、一句把话题交还对方的问题。
- 写法：先听对方行业和议题；只讲一个相关案例；以追问和继续交流为成功，不以讲完整为成功。
- 恢复问句：`你刚才听到的部分里，哪一点与你们当前最相关？`或`如果换成你，你会想先听哪类结果？`
- 成长指标：核心标签复述、主动追问、交换联系方式、二次会议。

## 4. 私域、微信、社群与朋友圈

- 默认技术：`F02 F07 F10 D02 D03 D06 D10 D14 D24 E01 E08 L04 L05 L07 L10 L12`。
- 默认交付：加好友首句、80-150字介绍、社群破冰版、一对一信任版、朋友圈置顶结构、低压力CTA。
- 写法：先说明连接原因和相关性，再讲能提供的帮助；保留人味、互惠和边界，不发履历墙或初见逼单。
- 成长指标：回复率、有效对话率、对方主动描述问题的比例、预约率。

## 5. 嘉宾、讲师、主持稿与演讲开场

- 默认技术：`F01 F04 D02 D03 D04 D05 D08 D20 D24 E01 E03 E04 E05 E09 E10 E11 L01 L07`。
- 默认交付：50字主持口播、100字嘉宾简介、200字正式简介、一页PPT层级、演讲者20秒开场。
- 写法：主持稿回答“为什么值得听接下来的内容”；最多三个主题相关证据；演讲者不重复头衔墙，直接进入观点、问题或场景。
- 练习：正侧面录像，检查下巴、视线、呼吸、停顿和长机构名；E11只作身体提示。
- 成长指标：主办方采用率、主题标签复述、会后问题是否进入目标议题。

## 6. 合作伙伴、项目提案、招商与投资沟通

- 默认技术：`F04 F05 F06 D02 D03 D04 D06 D08 D14 D18 D19 D21 D24 E06 E07 E08 L04 L07 L12`。
- 默认交付：一句话合作定位、30秒项目介绍、资源互补表达、一个代表案例、下一步会议目标。
- 写法：强调共同结果、本人角色、交付边界、可核验证据；接到诊断、试点、资料清单或决策会。
- 禁忌：把“认识”写成“可调动”，把接触写成合作，把试点写成规模化成果。
- 成长指标：有效补充问题、资料交换、试点推进、决策人进入下一阶段。

## 7. 求职、晋升与跨行转型

- 默认技术：`F04 F10 F12 F14 F15 F16 F17 D02 D03 D04 D06 D13 D20 D24 E06 E07 E10 L01 L06 L07 L09`。
- 默认交付：30秒面试版、60秒自我介绍、岗位匹配三证据、转型叙事、一个反向提问。
- 写法：回答“能为岗位创造什么”；用可迁移能力和具体成果；诚实解释断层和短板，不虚构连续性。
- 练习：准备三类异议，先复述再回应；不以“我不太会表达”开场。
- 成长指标：追问是否命中目标能力、下一轮率、用人方对匹配度的具体反馈。

## 8. 个人名片、长图、一页PPT与商务手册

- 默认技术：`F01 F02 F04 F06 D02 D03 D04 D06 D08 D13 D21 D24 L10 L11 L12`。
- 信息层级：姓名和一个结果型标签；对象、问题与结果；一个机制；三条强证据；代表案例；合作入口；一个CTA。
- 视觉原则：首屏先见人名、定位和结果；证据有层级；客户Logo配准确关系口径；真人、作品、产品和案例优先于氛围图。
- 验收：手机和桌面均可扫描，无重叠截断；联系方式只在用户明确提供并同意后加入。
- 成长指标：五秒复述准确率、扫码/咨询率、哪条证据被停留或追问。

## 9. 信息不足时的路由

- 有经历无结果：`F04 + D17 + L02`挖前后变化。
- 有愿景无业绩：`F16 + D07 + D19 + L03`写成行动和试点。
- 身份太多：`F01 + D03 + D04 + D21 + D22`做一点突破。
- 不敢说出口：`F07 + F08 + F12 + F17 + L06 + L09`先对齐真实自我形象。
- 文案好但现场冷：`E01 + E04 + E08 + E09 + L07 + L08`检查接收和反馈。
- 线上线下不一致：`F17 + L10 + L11 + L12`统一足迹和持续行动。
