# 项目任务书

## 核心目标

用户只需要提供简短个人介绍和使用场景，系统就能生成商业级、可信、能直接使用的自我介绍与个人展示资产。

## 主要场景

- 抖音置顶视频
- 视频号主页或置顶视频
- 自媒体平台简介
- 商务饭局和线下社交
- 私域欢迎语与朋友圈介绍
- 嘉宾、讲师、主持人口播介绍
- 商务资料、个人名片、长图和单页展示

## 输入最小集

- 人是谁：经历、当前业务、优势、产品、案例或结果的粗略描述。
- 用在哪里：平台、场合、听众和预期动作。

证据、语气、隐私边界、禁用表述和行动号召是增强信息，不应成为生成第一版的强制门槛。

## 输出原则

- 先判断定位，再写文案。
- 一个代表性听众、一个核心价值、一个可观察的下一步。
- 用真实证明支撑商业承诺。
- 针对不同场景重构，而不是机械缩短同一段文字。
- 同时给出口播、文字、展示结构和后续迭代方法。

## 方法来源

- 横川裕之《自我介绍的技术》四阶段 64 项技术。
- 用户关于 Prompt、Skill、交付闭环、结果验收和资产沉淀的商业认知。
- 内容 LOOP 与增长 LOOP。
- 个人品牌、短视频表达和中国商业传播合规参考。

## 最终产品方向

当前交付是可复用 Skill 和一个完整样例。下一阶段可以在不破坏 Skill 的前提下，继续发展为：

- 结构化问卷和证据采集器。
- 多场景文案生成器。
- 个人介绍长图、单页、PPT 和视频脚本生成器。
- 版本管理、真实反馈和 A/B 迭代面板。
- 案例库、证明材料库和个人品牌资产库。
