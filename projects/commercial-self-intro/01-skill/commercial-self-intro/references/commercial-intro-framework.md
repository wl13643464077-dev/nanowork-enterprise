# 商业自我介绍总框架

## 1. 核心判断

普通自我介绍回答“我是谁”。商业自我介绍回答四件事：为谁、在什么场景、创造什么变化、凭什么相信。身份和履历只在能支持这四件事时出现。

本 Skill 将全书方法编成四个连续阶段：

`认知与挖掘 F -> 目标与设计 D -> 现场表达 E -> 实践与升级 L`

它不是把64项技巧塞进同一段话，而是把64项都变成可选择、可追踪、可验收的技术节点。

## 2. 两个 LOOP

### 内容 LOOP：生成当下版本

- `Listener`：一个具体听众、当下状态、显性和隐性需求、熟悉的词、理想反应。
- `Outcome`：因为此人参与，听众能看见的未来或商业结果。
- `Ownable Proof`：与承诺最相关、可归属、可核验且不夸大的证据。
- `Prompt`：符合关系强度的一个下一步。

### 成长 LOOP：让版本持续变强

- `Launch`：把有版本号的介绍放进真实场景。
- `Observe`：记录复述、追问、异议、行为和一个主指标。
- `Optimize`：每轮只改一个变量，避免无法归因。
- `Preserve`：保留赢家、证据、反馈和适用场景，形成个人表达资产库。

内容 LOOP 解决“这次怎么说”，成长 LOOP 解决“下次为什么更好”。

## 3. 四阶段技术路由

### F：先确定本人能长期兑现的形象

用于输入模糊、自我否定、价值不清、经历很多但没有主线时。重点寻找普通工作中的隐藏价值、理想自我、独特角色和可持续行为。常用组合：`F02 + F04 + F07 + F14/F15 + F17`。

### D：把价值加工成场景结构

用于所有成稿。先定目的和单一听众，再从受益型、展望型、18秒、1分钟、试点型中选择结构。常用组合：`D02 + D04 + D09 + D10 + D18 + D24`。

### E：让信息真正进入对话

用于口播、演讲、饭局、面谈、直播、面试。重点不是表演流利，而是营造接收状态、尊重时间、观察反应和处理异议。常用组合：`E01 + E04 + E05 + E08 + E10`。

### L：把一次介绍变成长期资产

用于所有交付，尤其是发布后改稿。必须至少安排真实使用和反馈动作。常用组合：`L01 + L04 + L07 + L10 + L12`。

## 4. 证据梯度

按相关性优先，不按“听起来厉害”优先：

1. 同类场景的前后结果、时间、成本、错误率、转化或行为变化。
2. 具体案例：谁遇到什么问题、做了什么、结果如何、本人贡献是什么。
3. 可展示作品、产品、流程、数据、专利或方法。
4. 可验证岗位、证书、出版、演讲和任职。
5. 与当前问题有关的长期经历或跨界经验。
6. 准确说明合作范围的品牌或机构关系。
7. 没有结果证据时的诚实试点方案。

一条相关证据强于十个无关头衔。因果不清时写“参与、帮助、贡献”，不用“实现、保证、带来”。

## 5. 五种结构

### 受益型一句话

`我帮助[具体人群]，把[现状A]变成[具体未来B]。`

### 展望型一句话

`我正在通过[具体行动]，让[具体人群]更接近[可想象未来B]。`

### 18秒三句话

`未来 -> 一个最相关证明 -> 一个现在行动`

### 1分钟梦想结构

`想创造的未来 -> 为什么开始 -> 正在做什么 -> 别人将获得什么`

### 无业绩试点型

`我正在解决[问题] -> 已具备[能力/机制] -> 寻找[匹配试点对象] -> 约定[边界、交付、反馈]`

## 6. 用户的商业操作原则

- 先说可感知结果，再说身份。
- 能力必须进入具体人群、场景、动作和验收。
- 承诺必须带证据、边界和责任范围。
- 一次表达要沉淀为可复用版本、证据和反馈资产。
- 介绍只是关系入口，不把第一次接触变成完整成交会。

资产链路：

`简短输入 -> 价值挖掘 -> 技术选择卡 -> 场景版本 -> 练习与发布 -> 数据与反馈 -> 单变量改写 -> 赢家和证据沉淀`

## 7. 场景指标

- 短视频：前3秒留存、完播、主页访问、关注或私信率。
- 主页简介：主页到私信、咨询或链接点击的转化。
- 私域：回复率、有效对话率、预约率。
- 商务场合：正确复述率、主动追问数、联系方式交换率、二次会谈率。
- 嘉宾与演讲：主持稿采用率、观众对核心标签的复述、会后相关问题数。
- 求职与晋升：面试官追问是否进入目标能力、下一轮率、岗位匹配反馈。

每轮只选择一个主指标和一个改动变量。

## 8. 非科学化与现代边界

- `D16`的18象征、王牌意象仅作为写前心理预备。
- `D23`姓名拆解仅是创意记忆法，不推断性格或命运。
- `E11`腹部和脊柱仅作呼吸与身体意象，不作医学、声学结论。
- “扮演理想自我”只指练习符合目标的真实行为，绝不伪造身份和成绩。
- 书中时代性案例、排名、机构和绝对化说法必须按当前事实和规则重新核验。
