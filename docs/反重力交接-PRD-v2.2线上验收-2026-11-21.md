**排查入口**　先用下列命令复现空候选，再查 `server/src/engines/ai.js` 中地点如何触发结构化检索，以及 `server/src/engines/market-scan-research.js` 如何统计覆盖度。#535 太原吾悦广场成功取回 75 条餐饮 POI，其中 68 条有人均；T10 高德三步自检也已通过。

```bash
node --input-type=module <<'JS'
import { normalizeLocationIntent } from './server/src/engines/location-intelligence.js';
for (const question of [
  '北京望京商圈餐饮的客单价是什么范围，有哪些代表的店，再具体看下火锅及火锅相似竞品',

  '广东菜 太原吾悦广场 我要看看周围有没有竞争对手 对手啥情况',
]) console.log(normalizeLocationIntent(question).centerCandidates);

```

**验收**　两条望京原话能解析到相应地点，太原仍定位正确。实跑时核对地图和其他允许的公开来源；地图不可用时保留有出处的公开检索结果。正文至少三档价格，按去重门店给出可追溯的数量。少于 15 家就在首段说清实际数量和原因，标明参考价、推测和缺失字段。用太原作对照时也检查 36 元、42 元是否进入正确价格档，以及“未查到粤菜正餐”是否被写成了“竞争空白”。

## 2. T4 · 预算已给，优化面板没有可改的预算

**复现**　演示企业的[任务 #536](https://纳米work.cn/tasks?kind=restaurant&id=536) 对应产出 #554。店小满收到 3,000 元预算，方案有预算拆分，原稿“七、可改的假设”列了 6 项。报告优化面板却显示 0 张卡片。离线仅去掉标题中的“七、”即可解析出 6 项，其中仍没有活动预算。

**排查入口**　`server/src/engines/report-assumptions.js` 负责解析表格；同时查派单中已确认的预算如何进入假设表。重算和界面分别见 `server/src/engines/report-refine.js`、`web/src/components/ReportRefinePanel.tsx`。可用 #554 原文回归历史格式。

**验收**　旧格式能显示假设；有明确预算的活动单能编辑真实预算。例如把 3,000 元改为 1,500 元，点击“按新假设重算”，在 60 秒内得到新版。核对预算分项、合计及受影响的数量，同时对照无关段落及保留的原稿。记录任务号、两个版本和实际耗时。
