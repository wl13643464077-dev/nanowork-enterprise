## 三、登录页重做（P0，你最不满的地方，3-5 天）

### 3.1 为什么现在显得廉价（10 条具体技术原因）

**1. canvas 粒子连线是 2014-2018 年 particles.js 的标志性套路。** `Login.tsx:67-93` 与 particles.js 的 `linkParticles` 逐行同构：遍历点 → 算距离 → 小于阈值画线 → 透明度按距离线性衰减。这个视觉在 2018 年被中国 SaaS/区块链/AI 官网大规模套用，现在是"模板站"的强信号。

**2. 全部动效匀速线性，零缓动。**
```css
.nw-orbit-a{...animation:nw-spin 24s linear infinite}
@keyframes nw-spin{to{transform:rotate(360deg)}}
```
两个轨道都 `linear infinite`，无加减速、无节奏变化 —— 这是"屏保感"。粒子同理：`Login.tsx:58-59` `vx/vy = (Math.random()-0.5)*0.18` 是恒定速度直线运动，无加速度、无噪声场（Perlin/Simplex）、无鼠标交互力场。**高端动效的核心是缓动曲线和节奏。**

**3. 无景深、无层次。** `Login.tsx:60-61` 半径 `1 + random()*1.8`、alpha `0.28 + random()*0.5` 是**独立随机**的，没有建立"小且暗=远、大且亮=近"的关联，也没有对应的视差速度差。结果是一片扁平噪点。

**4. 连线几乎不可见 —— 付了计算成本没有视觉产出。**
```js
context.strokeStyle = `rgba(65, 134, 224, ${(1 - distance / 132) * 0.18})`;
context.lineWidth = 0.7;
```
最大 alpha **0.18**、线宽 0.7px、颜色 `#4186e0` 压在 `#041326`→`#071d36` 深蓝底上；再叠 `.nw-network{opacity:.86}`（L220），**有效 alpha ≈ 0.155**。用户看到的是"一堆几乎不动、几乎看不见的小点"。

**5. 六个装饰层缺乏统一视觉语言。** canvas 粒子 + `.nw-grid` 方格 + 2 个 `.nw-orbit` 同心圆 + `.nw-auth-glow` 520px 径向光斑 + 3 层背景渐变。**粒子网络、方格网格、同心圆轨道三种几何语言互不相关**，是"装饰堆料"而非设计。

**6. 毛玻璃白付成本。** `Login.tsx:226` `background: rgba(248,252,255,.96)` + `backdrop-filter: blur(20px)` —— **0.96 不透明度基本抵消了 blur 效果**，付了合成成本却看不到玻璃感。真正的玻璃拟态需要 0.6-0.8 透明度 + 边缘高光。

**7. 字重/字距处理过火。** `font-weight:760`（L223）是非标准值，Noto Sans SC 只有 9 档，760 会被舍入或触发合成加粗。`.nw-copy h1{letter-spacing:-3.2px}`（L224）—— **中文标题负 3.2px 字距会让汉字明显挤在一起**，负字距是拉丁大标题的技巧，方块字用会破坏字面平衡。L230 移动端又改成 -1.8px，说明作者感觉到问题但没找到根因。

**8. `.nw-route` 流程箭头是 2010 年代 CSS 三角 hack**（`border-left:4px solid` + 上下透明边框），SVG 唾手可得的今天属于技术债，且无法做描边动画。

**9. 整页无进场编排。** 只有 3 个 `.nw-signal` 有 110ms 错峰。品牌 lockup、大标题、副文案、登录卡**全部同时出现**，无 stagger、无 mask reveal、无 blur-in。**高端登录页的第一印象来自 0-800ms 的进场编排，这里完全没有。**

**10. 无视 midnight 主题。** 整页写死深色，用户设成明亮主题后：登录深蓝科技风 → 进入后突然变白 → 体验断裂。

### 3.4 重做方案

**方案 A（推荐，性能优先）—— CSS mesh gradient + 分层进场编排**

对齐 2026 主流基准（Stripe/Linear/Vercel 的"高级渐变"观感，无 canvas 开销、低耗电）：

1. **删除** `Login.tsx:37-105` 整个 canvas 块、L221 两个 `linear infinite` 轨道、L220 的 `.nw-grid` 方格
2. **背景**：3-4 层重叠 `radial-gradient` 色团，`@keyframes` 周期 **12-18s**、`ease-in-out`，位移幅度控制在视口 10% 以内 —— 环境化、不抢注意力。全部走 `transform`/`opacity`，GPU 加速
3. **品牌动效**：纳米Work 六边形 N 的 SVG 描边 draw-in（`stroke-dasharray` + `stroke-dashoffset`，800ms `--ease-out`），比粒子更有品牌资产价值
4. **进场编排**（这是"高端感"的真正来源）：品牌 0ms → 大标题 120ms → 副文案 200ms → 信任标签 280ms → 登录卡 160ms，每级 `translateY(12px) + opacity 0→1 + blur(4px)→0`，`--dur-slow` + `--ease-out`
5. **毛玻璃修正**：卡片背景 `rgba(255,255,255,.72)` + `backdrop-filter: blur(24px) saturate(1.4)` + `inset 0 1px rgba(255,255,255,.6)` 边缘高光 —— 让 blur 真正可见
6. **字距修正**：`letter-spacing: -3.2px` → `-0.5px`；`font-weight: 760` → `700`
7. **响应主题**：明亮主题用浅色 mesh + 深色文字，深色主题用现在的深蓝 mesh
8. **`prefers-reduced-motion`**：mesh 停在静态帧，进场改为纯 opacity 淡入

**方案 B（视觉冲击优先）—— WebGL shader**

若要把登录页作为品牌差异化入口，用 Three.js / R3F 做单一 fragment shader（流体或 raymarched 几何）。注意行业提醒：「shader 背景已从 Stripe 独占变成大众商品（Framer 有 Shaders 库、Vercel v0 有 shader hero 模板），**顶级与合格的差别只在执行质量**」。成本约 5-8 天且增加约 150KB 依赖，**不建议作为第一期**。
