# 数字员工专家卡 · 2026-11 调研原件与待补清单

> 生成日期：2026-11-25。本目录的 `dept-*.json` 是八个分部的调研原件，由 `scripts/merge-expert-cards.mjs` 合并进 `server/catalog/employee-skills-supplement.json`（id 前缀 `supp-2026-11b:`）。
> 原技能目录 `server/catalog/employee-skills.json` 与 `restaurant.json` 未改动。

## 为什么做这一轮

甲方反馈数字员工「达不到行业专家级别」。查代码后的原因：

- 原技能卡 344 张（餐饮），平均 94 字，约四成来源是海外博客与厂商；全库没有引用《食品安全法》《劳动合同法》，也没有中国烹饪协会、CCFA 的行业数据。
- 首批补充卡 163 张，平均 58 字，多为「改用中国平台、换个取数办法」的提示，缺基准数字、法规条款和判定阈值。
- 补充卡要老板或管理员在员工技能页启用后才进入派活提示词；未启用时员工只按原卡作答。

## 这一轮补了什么

## 怎么让它生效

专家卡和首批补充卡走同一套审核：用老板或管理员账号打开某位员工的工作台 → 完整技能库 → 「全部启用待确认的 N 张」，或逐张确认。启用是按企业记录的，每家企业各自决定。未启用的卡不会进入派活提示词。

## 可信度：做了什么、没做什么

- 调研要求每个数字和条款都出自实际打开过的页面；找不到出处的不写，列入下方待补清单。
- 合并前从行业基准与法规条款两类里按固定间隔抽了 30 张，交给独立核查员逐项对照来源原文：27 张完全一致，3 张有个别条号或适用范围偏差（已按原文修正），0 张核心内容错误。抽中的卡在原件里带 `spotCheck` 字段。
- 抽查比例约 11%（30 / 270）。按这个结果推算，其余未抽查的基准与法规卡里仍可能有一成左右存在同类小偏差，**启用前请对你最在意的岗位再看一遍**。诊断方法与常见误判两类没有抽查。
- `confidence: medium`（142 张）表示数字出自媒体或二手转述，审核页会标「二手来源，启用前建议复核」。
- 多部法律条文读的是维基文库或高校转载文本，因为国家法律法规数据库页面无法直接抓取；条号以官方文本为准。
- 部分判定阈值是调研员依据样本设定的经验线，不是来源原文，已写在每张卡的口径说明里；进入提示词时会带上，并提示模型不要把它说成法规要求。
- 调研中途联网搜索额度用尽，后半程只能打开已知网址，所以行业基准类比法规类薄。
- 没有用真实模型跑升级前后的对比派单，这一轮验证的是卡片内容与装配逻辑，不是最终答题效果。

## 调研中发现的现行法规变动

- 《食品安全法》2025-09-12 第三次修正，2025-12-01 施行。
- 原总局令第 60 号已由第 97 号令修正并更名为《食品生产经营企业落实食品安全主体责任监督管理规定》，2025-04-15 施行，条文序号后移。
- 《网络餐饮服务食品安全监督管理办法》已于 2026-06-01 废止，由总局令第 123 号取代。
- 《食品召回管理办法》新规（总局令第 122 号）2026-12-01 施行，卡片写了新旧两套时限。
- 《通信短信息服务管理规定》已换为工信部令第 74 号，2026-05-01 施行。
- 《反不正当竞争法》2025 年修订，2025-10-15 施行，条序与罚则有变。
- 《餐饮业经营管理办法（试行）》已于 2025-06-15 废止，由《餐饮业促进和经营管理办法》取代。
- GB 30531-2014（商用燃气灶具能效）已废止，现行为 GB 30720-2025。
- 餐饮已不纳入环评管理；营业前消防安全检查没有面积豁免。原技能卡里的相应说法已用常见误判卡纠正。

## 线上实测后的修正：对标样本标注业态

2026-11-27 在线上给 #150 昌本利派了一单成本结构诊断（任务 #556）。答案用上了分业态基准和口径提醒，但把小菜园（大众中餐）、九毛九（酸菜鱼为主）的数字并进了“火锅”参照区间。原因是基准卡把几家公司的数字并排写，没有逐个标明业态。

修正方式：

- `scripts/merge-expert-cards.mjs` 合并时给每张卡里每个品牌首次出现处补上业态，如 `海底捞〔火锅〕`、`小菜园〔大众中餐〕`、`九毛九〔多品牌集团，酸菜鱼为主〕`，共 112 张卡受影响；调研原件不改。品牌与业态的对应表在脚本的 `BRAND_FORMATS` 里，新增品牌时在那里补。
- 提示词增加规则：只拿同业态样本做对标并算区间，其他业态的数只作旁证并写明业态；同业态样本不足两家时直接说样本不足。

### 第二步：区间句子按同业态重写

业态标注上线后复测（任务 #557）：食材、人工已只对标火锅品牌，但 Prime Cost、水电、租金仍沿用了卡片正文里现成的跨业态区间（如“火锅和重服务品牌 65%–73%”，下限其实是九毛九集团的数）。

于是筛出 86 张混有两种以上业态品牌的卡逐张检查，改写其中 31 张，55 张只是并列举例、保持原样。规则：

- 区间只用同业态样本计算并点名样本，如“火锅类（海底捞、呷哺呷哺）69.8%–73.1%”“中式正餐类（小菜园、绿茶）55.3%–57.8%”。
- 同业态只有一家样本的不给区间，写“仅 X 一家样本”。
- 九毛九集团口径的数单列，不并入任何业态。
- 不引入任何新数字：合并前用脚本核对，改写后的每个数字都在原文里出现过，且只改了标题、正文、备注三个字段。

仍需注意：个别卡没有样本可分组（107-5、126-8、129-7），只能加注“跨业态粗略归纳，不是某一业态的区间”；部分阈值取自单一公司，已在卡内写明取自哪家。

## 顺带修正的旧卡

`supp-2026-11:118:01`「中国温度口径」原写冷藏 0~10℃、冷冻不高于 -18℃ 并标注出自《餐饮服务食品安全操作规范》。操作规范原文是冷藏 0~8℃、冷冻宜低于 -12℃；0~10℃ 与 -18℃ 是 GB 31605 冷链物流的口径。已更正并注明两者的适用环节。
