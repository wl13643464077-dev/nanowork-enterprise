# 纳米Work真实验收桌面编排说明

## 范围

- 员工总数按权威接口口径为72：餐饮61（60核心 + #161巡店扩展）以及内容11（10个派活AI + 原生AI带货员idx10）。
- 每个已执行员工目录只允许三个交付文件：`01输入.md`、`02输出.md`、`03执行与费用报告.md`。失败、超时和安全阻断同样保留这三份真实证据，不用模板伪造成功输出。
- 全功能清单从 `web/src/App.tsx`、`web/src/layouts/MainLayout.tsx`、`server/src/app.js` 和 `server/src/routes` 静态盘点，再合并真实功能矩阵与浏览器证据；静态入口不计作已执行。

## 隔离命令

```sh
MATRIX_USERNAME=guan MATRIX_PASSWORD=... \
node scripts/export-real-matrix-desktop.mjs \
  --out-dir "$HOME/Desktop/NanoWork-真实验收-<timestamp>" \
  --timeout-ms 900000
```

编排器从 `server/data/nanowork-real-final-2026-07-31-v1.db` 复制专用 SQLite，写入员工/功能双隔离标记，启动随机 `127.0.0.1` 端口，`ENABLE_SCHEDULER=false`，运行结束停止服务。账务以该专用库 `credit_holds`/`credit_logs` 为权威；API Key 仅由已启动服务环境读取，测试脚本、日志和桌面文件均不读取、回显或保存。

## 受控视频安全门

原生AI带货员只在云雾通道、允许模型、正数视频价格和合成器元数据全部就绪时发起一次最低成本30秒任务；任一门未满足则调用业务路由取得 `BLOCKED` 快照，供应商调用数和费用必须为0，不把阻断写成成功。

## 费用口径

供应商成本估算与客户账本实扣分开；未知模型价格或未发生调用写 `N/A`，不写0冒充免费。若账务已结算但服务端 provider 快照缺失，报告标为“账务API已结算（provider快照缺失）”，判定仍为失败，等待生产侧补齐调用证据。
