# Wan2.6 与 Image2 真实验收

用户要求用其上传的照片实际调用 API，修复有声视频配置阻断、改善小红书图文，并将输入与输出放到桌面。测试输入为应用内的罗二火锅门头和火锅桌面两张照片，未使用演示图片替代。

## 交付和验证

- Wan2.6 原生声音链路真实生成两段 15 秒视频并合成 30 秒竖屏成片，没有调用额外 TTS。下载、音轨、画面和烧录字幕均有实际文件证据。字幕描边问题已修正，使用原始 API 片段本地重新合成，未重复支付视频生成费用。
- Image2 使用用户上传的参考图片，通过 `/v1/images/edits` 真正调用 `gpt-image-2`。首轮两图成功、一图超时；修正生成提示词与后台超时后，对菜品特写、用餐氛围分别另次补测成功。推荐包为三张图片。旧图和失败记录保留对比。
- 小红书在首轮后又真实调用一次文字模型，输出更自然的标题、正文、标签和首评。本次文字优化没有重新请求全部配图。
- 后台与前端已更新，本地 3107 服务正常。实际浏览器核对了两个数字员工工作台：Wan2.6 默认有声、无单独声音授权门槛；小红书默认三张图，AI 成年女性为可选项。
- 自动化全套 2407 项，2406 通过、0 失败、1 项因环境缺少 DOCX 渲染器跳过。类型、严格 lint、格式、隔离、令牌、UI 合同与构建检查通过。末次报价文案纠正后 UI 合同 14/14 通过，再次构建通过。

## 删除与简化

删除 Wan 新任务额外 TTS 的授权、公网音频地址与选择步骤，保留历史任务兼容。取消旁白最低字数硬门槛；不为负面提示“不要编造最新优惠”触发无关联网研究。小红书图片提示词只保留品牌事实和单张视觉任务，去掉整段正文和技能说明，避免生成拼贴海报。文案与图片独立交付，图片局部失败不会丢弃可用结果；未知费用不自动重试。

## 证据边界

测试调用正式生产路由和引擎、真实配置供应商，业务记录写入正式数据库的隔离备份。正式余额、用户数、内容数与媒体任务数在服务重启前后均不变；供应商侧调用真实发生。报告中的计费来自平台配置，不等于供应商账单已核验。

字幕依据脚本估时，尚非逐字识别对齐。本机 tiny ASR 确认两段有中文独白，但有错字和尾部低置信幻觉，不能替代人工听辨。首轮视频口播包含拍摄指令；后续提示词已排除这类内容，本轮没有为该修改再次付费生成成片，报告保留首轮真实表现。

首轮场景图费用仍待核对：旧预授权 180 积分保持 pending_reconciliation，不以另次补测成功冒充原任务成功或已退款。
