# 带货默认15秒与声音输入能力核查

本轮要求：不为凑30秒拼接两个不同音色，默认15秒，用户可勾选30秒；到现有中转站核查能否上传声音、固定用户音色。

## 实现

- 新对话默认 `options.durationSeconds=15`，15秒一段口播、一次Wan2.6原生音画生成。30秒需要明确选择，使用两段15秒，界面说明分段音色可能不同。
- 用户文字中的明确时长与勾选同步；否定句、镜头位置时间不擅自扩大生成费用。切换时长使旧稿不可确认，媒体执行绑定已确认方案的时长与版本。
- 报价、预授权、实际结算、字幕、成片时长检查和恢复都按一段或两段执行，前端直接读取后端两档报价，不自行折算。15秒没有第二段和转场，也没有外部TTS。
- 历史缺少duration及新报价字段时仍按原30秒、原fingerprint/预授权恢复，不重新计价，不把旧确认稿解释成15秒。视频核心拒绝执行时长与已确认方案不一致。
- 数字员工档案、卡片、例句、“照样片做一条”和派活指引同步默认15秒。旧海螺30秒恢复逻辑保留，不作为当前默认有声生成方式。
- 未修改用户旧技能原文、历史或账户权限。

## 中转站核查

已只读查看[OpenLux模型广场](https://api.openlux.ai/pricing?keyword=wan)与[百炼视频接口文档](https://doc.openlux.ai/reference/alibailian?op=post-alibailian-api-v1-services-aigc-video-generation-video-synthesis&leaf=359496147)。搜索wan列出视频模型 `wan2.6-i2v`、`wan2.5-i2v-preview`，以及图片模型 `wan2.7-image-pro`，未见万相2.0或参考生视频模型。

当前 `wan2.6-i2v` 模型卡明确列出自定义音频输入，官方 `input.audio_url` 支持WAV/MP3、3–30秒、最多15MB。用途是使用已经录好本次台词的音轨，不等同于提取音色后说任意新稿。[官方图生视频文档](https://help.aliyun.com/zh/model-studio/legacy-image-to-video-api-reference/)

官方 `wan2.6-r2v` 可以从本人说话视频参考角色形象和音色；`wan2.7-r2v` 文档另有仅参考音色的 `reference_voice`。这两个视频模型未在本中转站已列清单中找到，不能宣称当前可用。[2.6参考生视频](https://help.aliyun.com/zh/model-studio/legacy-wan-reference-to-video-api-reference)、[2.7音色参考](https://help.aliyun.com/zh/model-studio/wan-video-to-video-api-reference)

项目供应商适配器已有audioUrl字段映射，但当前带货流程主动省略它；本轮仅核查能力，没有添加用户录音上传入口，没有对用户声音做克隆或发起录音输入的付费测试。
