# 升级迭代产品简报

日期：2026-07-30

产品一句话：把当前“界面和流程能跑”的纳米Work，升级为员工能力真实生效、产出可验证、成本可控制、权限不越界的企业数字员工系统。

目标用户：企业老板、管理员、部门员工，以及维护平台租户与计费的平台主管。

核心痛点：

- 同一数字员工在不同执行入口能力不一致。
- 模板底稿被误认为真实交付。
- 外部 AI 调用、调度和密钥处理存在生产风险。
- 角色入口、数据范围和经营指标存在明显业务错误。

目标动作：关闭回归报告中的 P0 与高影响 P1，并用自动化、隔离 API 和真实浏览器证明修复成立。

成功指标：

- 启动无显式开关时不会运行自动化。
- 密钥不写 SQLite，错误不泄露凭据。
- 员工配置真实控制模型、长度、超时与联网行为。
- 严格岗位契约拒绝空值和错类型。
- 未完成底稿不计成功产出。
- 销售读取老板日报返回 403。
- 目标缺失时不显示伪百分比。
- 角色入口与后端权限一致。
- 全量测试、类型检查和构建通过。

交付等级：当前新项目内可运行、可回归的升级版本；本轮不对外发布。

硬约束：

- 不修改旧项目。
- 不覆盖用户现有未跟踪文件。
- 不调用真实付费服务。
- 不保存或复用已暴露密钥。
- 不执行 Git commit、push 或发布。

未知风险：统一外部调用和员工执行链可能触及较多历史入口；按垂直切片小步迁移，未迁移入口必须明确保留为发布阻断。

已跳过阶段及原因：市场压力测试与用户研究已跳过，本轮是现有产品的证据驱动缺陷升级。
