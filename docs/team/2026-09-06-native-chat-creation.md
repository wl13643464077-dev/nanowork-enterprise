# 数字员工对话创作迭代

目标：餐饮老板给主题和真实照片，员工负责理解、写稿和生成；老板看结果、选择是否采用。实现沿用数字员工、文件中心、任务中心和计费体系。

## 删除和简化

- 删除两岗前置的硬性创作表单，使用同一套持久化对话组件。
- 删除确认后的第二次文字生成；视频逐字复用确认脚本，小红书复用确认正文和配图方案。
- 正文、照片和成片优先展示，内部技能提示词、事实上下文不公开到老板的对话方案。
- 每岗提供三个可点击示例，仅填入草稿；用户补充实拍再发送。老板不需要写视频脚本。
- 使用已有本地文件、图片合成与ZIP依赖，没有增加第三方交付服务。

## 实现

- 两岗对话落库，按企业及创建者隔离；超时通过读取历史恢复，不自动重新提交付费请求。
- 最新用户消息使旧方案立即不可确认。确认携带方案版本，双击复用同一任务。
- 小红书支持6、9、12图，种草推荐、对比测评、点单攻略、聚餐探店、新品推荐、品牌故事六种风格。
- 封面支持食欲大图、四宫格和大字报。四宫格由四张不同的已生成原图本地合成，中文标题由本地排字。内容张数和视觉任务实际进入逐页生成。
- 不因部分配图失败丢弃正文和成功图片；每张图片记录独立调用与账目，未知结果保留待核验。
- 当前对话与统一任务中心可预览、复制正文和打包下载。下载只读取已保存成果，不生成、不扣费，不代替用户采纳。
- 用户后续编辑与采纳/不采纳仍沿用任务中心的结果版本和反馈学习。
- 视频原稿校验修复了自然品牌邀请被误拦的问题；本轮用户明确给出的品牌以用户消息作为来源。免费重新检查复用已付费原始回复，不重新调用模型。

## 参考与设计取舍

封面采用一个明确食物主体、短标题和清楚的信息层级，不把地址、评分、优惠全部堆到首图。参考美图设计室的[美食封面设计思路](https://www.designkit.cn/article/xhsmstdfmsjrhtsssdjl20250715)和其[美食测评拼贴模板](https://www.designkit.cn/template/893241911)。

四宫格、单品特写、点单指南的不同用途参考了[行业机构的餐饮内容分析](https://www.xiao-ad.com/zx/1990.html)。该机构不是小红书官方；没有将其增长数据或建议当作平台规则，也没有承诺自动发布、点击率或平台审核结果。
