## 回滚策略

1. 生产外部链路验收失败时立即关闭相应环境开关或连接器，不降级为“伪成功”模板。
2. 停止 Scheduler 和后台任务领取，等待在途任务进入终态。
3. 核对并释放可安全释放的悬挂占扣；结算状态不明的保留 `pending_reconciliation`，禁止强行改成功。
4. 恢复发布前数据库备份和上一个已验证版本。
5. 轮换可能暴露的凭据，并保留脱敏审计记录。
