# 统一任务历史与结果反馈

## 老板现在怎样使用

左侧「任务中心」，或内容生产仓右上方「全部历史 · 任务中心」。内容数字员工、餐饮数字员工、经营工具、普通生成内容及小红书图文等任务在这里汇总。点击一条任务，先看最终正文、媒体成果，再展开原始需求和上传素材。

有可查看成果的任务提供「采纳这份结果」「不采纳，保留原稿」，原因可填可不填。当前版本的选择会保存；正文或媒体换成新版本时，可对新版本重新选择，旧反馈不会套到新成果上。网络重试不会重复记一次选择。未完成且没有成果的任务不冒充可采纳结果。

反馈作为同企业、同账号、同岗位的表达与交付偏好，实际进入后续内容、原生小红书、原生带货视频、经营工具、餐饮员工、老板参谋的生成上下文。只点选择不填原因时，不猜测满意或不满意的具体原因；它也不会成为已核验的门店事实。没有可识别岗位的历史任务仅保存选择，不声称员工已学习。

采纳选择不自动发布、不改写真实费用与执行记录，也不把未成功的生成改成成功。旧成果保留供查看。
