# NanoWork 桌面客户端 QA 验收记录

更新日期：2026-08-23

## 当前结论

**状态：冻结源码、双架构 macOS 包与 Windows 交叉构建产物均已通过现阶段门禁；正式发布仍为 BLOCKED。**

本文件是 Windows / macOS 桌面客户端的可执行验收矩阵。结果只允许填写 `PASS`、`FAIL`、`BLOCKED`、`NOT RUN` 四种状态；没有命令输出、产物路径、哈希或实机记录时不得写成通过。

## 证据规则

- `PASS`：有可复现命令、退出码、关键输出和证据路径；实机项目还要记录系统、架构、客户端版本和执行时间。
- `FAIL`：已执行且不符合验收标准，必须记录复现步骤、实际结果和缺陷编号。
- `BLOCKED`：缺少外部前提，例如 Windows runner、签名证书、服务器或更新域名；必须说明解除条件。
- `NOT RUN`：尚未执行，不能与“未发现问题”混用。
- 日志必须脱敏；不得写入 Cookie、Bearer token、密码、`.env`、业务正文或服务器响应正文。
