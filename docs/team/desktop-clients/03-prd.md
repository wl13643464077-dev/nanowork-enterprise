# NanoWork 桌面客户端 PRD

更新日期：2026-08-23

## 用户路径

1. 用户安装并启动“纳米Work”。
2. 客户端读取已保存的服务器地址；首次默认连接 `http://127.0.0.1:3107`。
3. 连接成功后显示现有 NanoWork 登录页，登录后完整使用数字员工、内容生产、工具箱和管理能力。
4. 连接失败时给出“重试 / 修改地址 / 退出”。
5. 用户从应用菜单打开“服务器设置”，输入新地址，经过校验和健康检查后保存并重连。
6. 受保护文件从当前会话下载到系统下载目录，进度/成功/失败有原生反馈。
7. 业务网页部署后下次打开/刷新即生效；桌面壳新版本通过签名更新通道升级。

## 功能要求

### F1 安全远程容器

- 只加载当前配置的 NanoWork origin。
- 不向远程网页暴露 Node、Electron、文件系统或通用 IPC。
- 同源弹窗继承同一会话且使用同等安全选项；外部 HTTPS 链接交给系统浏览器。

### F2 服务器设置

- 默认值：`http://127.0.0.1:3107`。
- 允许 `https://...`；只对 `localhost` / loopback 允许 `http://`。
- 禁止用户名/密码 URL、query、hash、`file:`、`javascript:` 和其他协议。
- 保存前请求 `/api/health`；检查失败可选择继续保存，但必须明确告知。

### F3 离线/故障态

- 首次加载、DNS/连接拒绝、TLS 失败均进入可操作故障流程。
- 不禁用 TLS 验证，不提供“忽略证书”开关。

### F4 下载

- 受保护下载使用 Electron 会话，不丢失 HttpOnly Cookie。
- 文件名去除路径和控制字符；默认存入系统 Downloads，不自动打开下载文件。

### F5 更新

- 未配置发布 URL 或未签名的内测包不执行自动更新。
- 配置后在应用启动后检查，下载完成询问用户是否重启安装。
- macOS 自动更新必须签名；Windows 保持默认签名校验。

## 非功能要求

- 启动后 15 秒内给出业务页或明确故障反馈。
- 不记录 Cookie、Bearer、密码、服务器响应正文或业务数据。
- 客户端版本、平台、当前服务器 origin 可在“关于/设置”查看。

## 验收标准

- F1–F5 每项都有自动测试或实机路径证据。
- macOS arm64 内测包在本机启动、连接 3107、登录并打开 `/employees?employee=101`。
- Windows x64 包具有 `.exe`、`resources/app.asar` 和完整 runtime；CI 在 `windows-latest` 生成 `.exe` NSIS 安装器和 `.zip`。
- 包中不包含 `server/.env`、SQLite、uploads、AI key 或用户业务数据。

## 本轮不做

- iOS、Android、PWA。
- 离线 AI、内嵌后端、本地数据库同步。
- 没有证书时的伪签名、伪公证或对外发布。
