# 设计简报｜Quiet Command 安静经营指挥台

日期：2026-07-31

## 产品品类

面向实体门店老板与管理层的 AI 经营作业系统。它不是报表网站，也不是聊天机器人外壳；主对象是“经营任务及其产物”。

## 参考产品与取法

- Apple HIG：使用清晰层级、空间和对比让内容优先；材料效果只服务导航与浮层，不铺满业务卡片。
- Claude / Claude Code：把目标、执行过程和可复用产物分开呈现；长任务持续显示状态与需要人工介入的位置。
- Linear：导航后退、主内容前移；命令面板承接低频入口；统一标题、标签、筛选与 inspector 的位置。

## 视觉主张

瓷白经营画布、石墨信息层、单一钴蓝动作色、活的任务轨迹。少盒子、少边框、少常驻 chrome；用排版、留白和状态关系建立层级。

## 设计令牌

- 画布 `#F6F6F3`；主表面 `#FFFFFF`；深色导航 `#171A20`。
- 正文 `#1D232B`；次级 `#5E6875`；弱化 `#8B949E`；发丝线 `rgba(29,35,43,.09)`。
- 主动作 `#2F6BDA`；悬停 `#2558B7`；选中 `#EAF1FF`。
- 成功 `#2D7D5B`、警告 `#B66A21`、危险 `#B94343`，仅表达真实业务状态。
- 字号 12/13/14/16/20/28/36；正文不得低于 13px；数据使用 tabular figures。
- 间距 4/8/12/16/24/32/48；圆角只用 8/12/16；主页面卡片不用阴影，浮层只用一档柔和阴影。

## 信息架构与交互主张

- 默认为“可折叠导航 + 主内容”两区；老板助手变为按需 contextual inspector。
- 底部快捷栏并入命令面板和页面右上主动作。
- 数字员工采用目录/任务空间/审阅 inspector；内容仓采用阶段轨迹/当前产物/审阅 inspector。
- 任务状态原位推进，生成结果与同构 skeleton 交叉淡入；不使用全页等待或装饰性漂浮。
- 动效统一 120–260ms，并遵循 `prefers-reduced-motion`。

## 当前基线证据

- 1280×720 下，62px 顶栏、约 209px 左栏、257px 右助手、57px 底栏和 46px 页面栏共同挤压内容，主工作区约占 49%。
- 内容生产仓首屏约 244 个可见元素、52 个带边框元素；全站约 2,185 处内联样式，页面层级主要依赖白卡与边框。
- 数字员工和内容工位以等权卡片陈列，执行状态、阻塞点与产物不是第一视觉层。

## 验收

- 主工作区宽度 ≥70%；默认没有常驻右助手和底栏。
- 颜色、圆角、阴影、动效来自令牌；无蓝紫渐变按钮、超大胶囊或全站玻璃。
- 老板、运营和员工在 3 秒内能看懂当前位置、当前状态和下一步动作。
- 桌面与 375px 截图完成“基线 → 修复 → 复查”闭环；控制台 error/warning 为 0。

## 2026-08-08｜工作台与内容仓增量设计

### 数字员工派活

- 首屏只保留一个大输入框“告诉 TA 这次要解决什么”，一个可选附件区和一个“开始工作”主按钮。
- “行业、地点、知识、联网、模型、篇幅、技能、输出格式”移入后台自动解析；老板可在“本次会怎么做”折叠区查看系统补齐结果，但不必先填写。
- 首次使用的岗位说明压缩成一行示例；不再展示“开工前请准备……”长清单。
- 结果页用“正在理解 → 正在查资料 → 正在调用岗位能力 → 正在生成 → 已可使用/需要你确认”表达真实阶段，低风险任务不再出现无意义的“待审核”。

### 超级管理者审批设置

- 用四个清晰选项表达：普通结果自动可用、按风险分流、负责人确认、老板确认。
- 页面固定显示不可关闭的三条安全底线：高风险、真实付费、对外动作。
- 规则保存后给出一句自然语言预览，例如“普通内部结果自动可用；高风险和付费动作由老板确认”。

### 内容生产仓

- 顶部主导航以“数字员工 / 任务与结果 / 素材库 / 模板库 / 自动任务”为主，不再并列 AI 图片、AI 视频、AIPPT。
- 数字员工按四个 Paihuo 阶段和“增长转化”分组；AI 带货员放在增长转化首位，卡片强调“上传图片，生成 30 秒带货视频”。
- 卡片仅显示：解决的问题、最少输入、交付物、连接状态和派活按钮；完整能力七面板仍在老板侧抽屉。

### AI 带货员

- 上传区接受人物、商品/菜品、门头，支持缩略图、分类标签、删除和错误提示。
- 一句话目标下方只提供两个可选开关：画质优先/速度优先、是否使用人物口播；默认显示“MiniMax H3”，但不暴露分段数或供应商工程参数。
- 任务详情按三段镜头显示独立进度和重试；最终结果提供成片预览、下载、脚本/字幕/事实依据与费用明细。
- 无凭证显示“视频能力待开通”，仍允许先生成脚本和分镜；不得展示假的进度条或示例视频冒充结果。

### 统一任务中心

- 主导航使用明确名称“任务中心”，不再让用户在任务看板、执行页、员工历史和内容结果之间猜入口。
- 首屏为紧凑状态带：进行中、需要处理、已完成、失败、今日费用；下方按任务时间排列，不使用大面积等高白卡。
- 单行任务只保留员工头像/真实岗位图标、任务标题、当前步骤、进度、耗时、费用和“查看结果”；扩展证据放入侧栏或详情页。
- 图标统一使用项目现有 Ant Design 图标族，不用 emoji 充当业务图标；颜色只表达状态，不为每个岗位随机分配彩色装饰。
- 任务状态必须来自权威业务表；加载使用骨架行，空状态提供“去派活”，错误状态保留重试和可读原因。
