# 无成果最终失败退款接入

范围：本次接通 29 个非原生 AI 两阶段入口。所有验证使用独立临时 SQLite 和本地桩供应商；没有调用真实收费接口，没有修改生产数据库记录。

## 行为

- 同步生成或业务事务最终失败、没有本次可读成果：调用 `refundHold` 退回用户积分；供应商是否收费与用户退款分开记账，未知成本保留平台 pending，不伪造为零成本。
- 已持久化正文、图片或制品：保留成果，结算异常单独 pending。生成仍在进行时不退款。
- 成果探针匹配本次 hold、租户、创建者及权威业务引用；同会话旧稿、其他企业相同 JSON 字段不作为本次交付。探针读库失败时保留占扣，避免猜测退款。
- 特殊图片/素材 provider 从持久化 attempt 回读成果；没有探针且持久化状态不明时保守待核对。外部失败退款不授权自动再次付费生图，混合素材流程遇此状态停止补图；本地零成本检索为空的原有补图能力保留。
- 共用执行器由根任务调整为先持久化、再核验计费用量：已有 API 正文而缺 token 时先保留成果并 pending。模板/伪 API 的独立真实性门仍保留，不冒充成功输出。
