# 纳米 Work 测试员与客户体验指南

适用对象：获批的测试员、销售伙伴，以及管理体验活动的 Super 管理员。

## 1. 申请自己的测试员账号

1. 打开 `https://纳米work.cn/tester/apply`，也可以在首页登录面板点击「测试员申请」。
2. 填写本人姓名、手机号，设置账号及至少 8 位密码，阅读并同意申请和使用记录说明。
3. 提交后等待平台审核。Super 在「测试员与体验」中批准、拒绝或暂停申请。
4. 审核通过后，在网站登录，自动进入「测试员工作台」。

测试员仅使用自己的账号，不能创建子账号，不能进入企业业务管理或平台管理页面。请勿把账号、密码、API Key 给客户使用；客户应通过你的体验二维码进入 H5。

## 2. 选择供应商并申请自己的 API Key

测试员可以选择 OpenLux 或 360 智脑。新申请账号默认选择 OpenLux；已有测试员保留原来的 360 选择和 Key。两家的 Key 分开保存，不能混填。OpenLux 用户在自己的供应商账户中进入 API Key 管理页面创建 Key，并确认账户额度。

360 用户按下面步骤申请：

1. 打开 [360 官方注册 / 登录](https://ai.360.com/open/zh/login)，按页面提示注册或登录自己的账号。
2. 打开 [API Key 控制台](https://ai.360.com/open/zh/platform/account/keys)，按官方界面创建自己的 Key，复制完整内容；开启「返回消耗金额」，便于核对真实费用。
3. 在控制台确认当前组织、Key 所属项目及账户可用额度。模型信息可查看 [模型广场](https://ai.360.com/open/zh/models)。
4. 当前测试员与客户 H5 可选择全部 73 位数字员工（61 位餐饮员工、12 位内容员工），以文本问答体验各岗位。AI 带货员交付脚本、口播和分镜；AI 小红书种草员交付标题、正文、标签和配图方案。体验页不生成图片或视频文件。完整产品的 Image2 使用官方模型名 `openai/gpt-image-2`；具体可用情况以实际接口结果为准。

官方接入资料：[文档一](https://ai.360.com/docs/413292017e0)、[文档二](https://ai.360.com/docs/413292018e0)。控制台的按钮名称可能更新，请以 360 当时页面为准。

## 3. 把 Key 填进纳米 Work

1. 登录测试员工作台，在个人供应商设置中选择 OpenLux 或 360 智脑。
2. 将这家供应商的完整 Key 粘贴到密码框中，点击「保存 Key」。切换到另一家时，需要另行填写另一家的 Key。
3. 保存后仅显示掩码，产品不会将完整 Key 发给客户。要更换时，在对应供应商下粘贴新 Key 再保存。删除一家的 Key 不会删除另一家的 Key。
4. 在「数字员工」打开岗位选择框，可按部门筛选或搜索需求。每位员工都有介绍和「一句话使用我」示例，点击填入后修改为真实需求，再发送测试。
5. 结果保留在「我的输入与结果」，可以展开、折叠与复制正文。

切换只影响之后新建的本人对话和新二维码。在途对话、失败重试及旧二维码继续使用创建时绑定的供应商。所选供应商没有 Key 时不能调用，也不会自动使用另一家或平台的 Key。

如果出现错误，请保留错误内容和调用时间：余额不足时核对所绑定供应商的账单；Key 无效时核对粘贴内容和所属组织。360 的 1001 是广义参数错误，仅凭「模型不存在或未授权」不能确定是权限问题，应由平台对照官方示例核查接口、模型路由及参数。删除 Key 后，绑定这家供应商的未完成对话和二维码暂时不能继续生成，已有记录保留。

## 4. 生成客户体验 H5 与二维码

1. 打开「体验二维码」。
2. 填写邀请名称（例如「张三 · 火锅老板体验」）与销售手机号。
3. 点击「生成体验二维码」。生成的链接和二维码指向同一个移动 H5 宣传页。
4. 点击「下载二维码」保存图片，或者「复制链接」发送给客户；也可先「预览 H5」。

该邀请固定绑定当前测试员及创建时选择的供应商。H5 显示销售手机号和供应商，调用由该销售对应的个人 Key 承担。之后切换工作台供应商不会改变旧码。H5 不暴露 Key，也不要求客户填写 API Key。

## 5. 客户扫码后怎样体验

1. 客户扫码，看到产品介绍、可用数字员工和体验说明。
2. 填写称呼、手机号、可选的门店名称，阅读并同意记录说明后申请体验。
3. 测试员在「客户与使用记录」点击「同意体验」，或由 Super 后台审批。客户等待页会更新审核状态。
4. 通过后选择一位数字员工，输入门店需求。每次发送并成功获得回复，记为 1 次体验。
5. 每位获批客户最多体验 2 次成功问答。失败且没有可用结果时可重试；剩余次数以服务端为准，刷新页面不会补回次数。
6. 用完后保留已有输入输出，可展开与复制；页面显示邀请人联系方式，方便继续了解完整产品。

客户手机号、门店、主动选择的岗位、使用次数及对话内容会展示给邀请人和 Super 管理员。选择岗位不消耗体验次数。请只提交本次体验需要的经营信息。

## 6. 费用怎么算

测试员本人使用、其二维码关联客户的体验，均由绑定的个人供应商账户直接承担 API 费用。纳米 Work 不在测试员的平台算力余额中重复扣款。

金额随所用模型及实际消耗变化。360 对话模型为 `deepseek/deepseek-v4-flash`，OpenLux 为 `deepseek-v4-flash`；供应商账单可能不同，不按平台销售价格估算个人费用。

在记录中可查看供应商返回的成本：360 人民币回执直接计入，OpenLux 按已核验的 quota、USD 金额和供应商汇率换算为人民币。无法核实则显示「待供应商核实」。生成失败也可能产生上游成本，已知金额及失败记录保留；同一销售、同一供应商、同一扣款回执不重复累计。360 费用可对照 [用量与账单](https://ai.360.com/open/zh/platform/account/usage)，OpenLux 费用对照其个人账户账单。

普通企业付费账号使用平台 Key 时，两家通道统一按平台配置的「360 基准价 × 2」定价；后台真实采购成本仍按供应商分别记录。这与测试员自带 Key、直接支付上游实际费用的模式分开。

## 7. 查客户、使用详情和叫停

「客户看板」按近 7 天、30 天、90 天或全部时间展示申请、已体验、尚未体验和两次已用完的客户数，并可查看实际使用的数字员工、模型、每日活动、已核实费用与待核实调用。Super 的「销售与客户看板」还可按销售筛选。

「客户关注的功能」分别显示主动选择过、实际成功用过的客户人数。同一客户多次选择同一岗位只计一次，关注记录不代表购买意向预测。旧版同意说明下的客户不补记选岗兴趣，仍正常统计真实使用。仅选过但没有调用的岗位不会列入「实际使用的功能」。

看板的客户数量和状态按所选时间内申请的客户统计；调用、费用和选岗按事件发生时间统计，可能包含更早申请的客户。本人使用与客户使用分开：本人累计费用取后台核实汇总，输入与结果显示最近 100 条本人记录。旧记录缺少逐次调用日志时会注明历史留存记录，缺失重试不作推算。

测试员在「客户与使用记录」查看客户手机号、邀请来源、审批状态、已用次数和最近使用时间。点击「输入与结果」查看具体需求、结果及可核实成本；可批准、拒绝、暂停或恢复客户体验。

在「体验二维码」可停用邀请入口。Super 在「测试员与体验」中查看所有测试员、邀请二维码、客户申请和详细输入输出，也可审批客户申请。

Super 点击测试员的「立即叫停」，即可禁止该账号及其关联客户继续发起新生成；已有记录保留。恢复账号不会重置客户已用次数。已提交到供应商的生成可能已产生费用，不应将暂停理解为上游账单撤销。

## 常见问题

- **申请后不能使用？** 检查是否通过审核，以及所选供应商是否已填写有效的个人 Key。
- **切换供应商后旧客户费用走哪里？** 旧二维码固定使用创建时的供应商，不会改走新选择，也不会重置两次额度。
- **客户一直等待审核？** 到客户列表批准该申请，让客户刷新状态。
- **客户提示入口不可用？** 检查二维码、客户和测试员账号是否被暂停，以及 Key 是否仍有效。
- **生成等待较久或页面断线？** 先刷新记录检查结果。服务端已完成的结果与次数不会因页面断线消失。
- **可以创建下属账号吗？** 测试员不可以。企业主账号及企业席位属于另一套权限与购买流程。
- **为什么客户不能无限体验？** 体验页开放全部数字员工的文字问答，最多两次成功问答；完整生产功能及继续使用需联系销售了解正式企业产品。
