# 纳米Work行业版 · 自主开发计划（2026-07-26 起）

> 授权背景：产品负责人开放全权限，由 AI 自主规划与持续开发，功能按 git worktree 分派子代理并行实施，验收合格合并回收，每轮升级同步 GitHub。
> 基线：分支 `claude/nanowork-enterprise-upgrade-vl1l1u` @ 第三轮迭代（341/341 测试全绿）。

## 总体目标

把第一~三轮报告中剩余的 P0/P1 路线全部落地，让产品达到「可对外交付」状态：

1. 餐饮真数据模型（门店/菜品/订单明细/成本）→ 真实客单价、毛利、菜品排行
2. 支付通道框架（微信 Native + 支付宝当面付，配置即用，未配置如实降级）
3. 死能力接通（飞书扫码绑群、数据来源地图、资产单条创建/编辑）
4. 业务数据 Excel 导出 + 前后端枚举统一
5. 长任务可取消 + 剩余静默吞错清理 + 壳层无障碍批量修复

**冲突控制**：文件边界互斥；`index.js` 仅允许各自新增一行挂载（合并冲突由主会话统一解决）；`MainLayout` 菜单新增由主会话在合并后统一接线。

**验收标准（每个代理必须自证）**：
- `npm --prefix server test` 全绿（不允许跳过既有用例）
- `cd web && npx tsc --noEmit` 通过
- 新增后端能力必须带测试；新增表必须进 `check-isolation.mjs` 监控清单且扫描无高危
- 全部 UI 文案中文、颜色/字号/间距用 theme token、无编造数据、错误态可重试
- 提交到各自 worktree 分支并在报告中给出：分支名、commit、文件清单、验证输出摘要

**合并流程**：主会话逐个 `git merge`（顺序 A→B→C→D→E）→ 解决 index.js/App.tsx 接线 → 全量 `npm run verify` → 截图抽查 → 更新报告与 CHANGELOG → push。
