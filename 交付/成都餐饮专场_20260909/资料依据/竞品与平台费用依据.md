# 成都餐饮专场：竞品、平台成本、360品牌事实核验

用途：2026年9月9日分享的演示文稿、演讲备注和备查材料。核验日：2026年9月5日（北京时间；工作区时区为9月4日）。只采用官方站点、监管部门、开发者自行提交的中国区 App Store 页面。本文不为纳米行业版设定销售价格。

## 1. 最重要的结论

1. **上上参谋与美团应分开讲。**上上参谋官网署名“深圳市数位汇聚科技有限公司”，App Store 提供者一致。不能在PPT里称“美团上上参谋”，也不能把“上上签”误作产品名称。公开材料仅能确认运营主体；本文未开展完整股权穿透，不宣称任何绝对的无投资关系。
2. **“会员＋按次／次数包并存”有一手公开依据。**可以强调比较时要同时看会员权益和专项评估费用；不能推断“每个会员每做一次都必须另外付费”。具体套餐的包含次数、可购买性与活动价仍须以当时购买页为准。
3. **美团佣金、配送、推广、商家优惠，必须分开核算。**官方公开的6%–8%指技术服务费/佣金，不能把商家承担的所有成本合并叫“平台抽成20%–30%”。
4. **适合产品销售的主张：把获客与经营主动权拿回来。**用“小红书种草—短视频获客—到店转化—会员复购—经营复盘”的自有能力说明纳米行业版价值，不能承诺停用美团就能降本或保证利润增长。
5. **360品牌可证实，行业版能力以本地产品核验为准。**用户已在会话中确认本行业版为360官方产品，数字岗位方法来自本人10年企业培训、3年企业转型经验；这是用户提供的内部事实，可用于讲稿。70多个岗位、11个功能等数量仍应以本地清单和实机为准，不能拿官方通用版的宣传替代行业版证据。
6. **最新竞品不是静止的。**美团已于2026年7月宣传CatPaw数字员工平台，不能写“美团只有流量没有数字员工”或“对手没有技能库”。

产品定位：官网标题为“连锁拓店管理系统”，提供用户版、企业版；开发者介绍重点包括开店选址、商圈分析、客群画像、人口热力、行业分布、外卖选址、找铺转铺和1v1定制选址。因此不应贬低为“仅卖一张数据表”。[上上参谋官网](https://www.sscanmou.com/)（未标发布日期；2026-09-05访问）

### 建议QA原稿

**Q：我已经买了上上参谋，为什么还要看纳米行业版？**

**A：选址数据解决的是“这里适不适合开”。纳米行业版要继续接住“开了以后谁来干”——今天的小红书图文、这周的视频、竞争对手动态、店长复盘、下一轮促销方案。我们建议您直接看三件东西：员工从哪里学会这份工作、交付的成品是什么、成品能不能在您的店里用起来。**

此答案中纳米交付项须与本地已验证功能对应；不要说能够替代上上参谋全部数据或拥有同等商业数据库。

**Q：他们的收费为什么要算两笔？**

**A：公开页面同时有会员商品，也有按次评估和次数包，选购时要把会员包含什么、专项任务是否另算一起看清楚。我们的年度服务范围与模型/API消耗也会分别说清，让老板按实际要交付的岗位和工作量选。**

这样既强调对方多种收费商品并存，也如实披露本方API按用量付费。不能把本方“年费＋API”描述为绝对没有附加成本。

### 未证实、不要写入的说法

- 上上参谋是美团旗下。
- 开会员后任何报告都要再付费，或所有项目都收两次钱。
- 专业版/企业版当前统一年费是多少、咨询服务必收多少钱（未取得有效公开报价）。
- 对方数据不安全、数据造假、只有提示词、没有真人方法论、没有AI能力。
- 把不同时间、渠道、会员等级的商品拼成一个“必付套餐”。

## 3. 美团：用净收益说明老板痛点

### 可核验收费口径

美团2024-12-25官方说明：费率改革后技术服务费（佣金）公开标准为6%–8%；商家选择美团配送时，履约服务费另按距离、时段、订单价格、天气等计价。商家给消费者的优惠属于商家补贴；不等同平台佣金。[美团：外卖真实佣金比例](https://www.meituan.com/news/NN241225051008799)

这属于**官方历史公开口径**，不应写成所有2026年商户合同的统一承诺。PPT如展示6%–8%，同屏标注“美团2024-12-25公开口径，实际以门店合同与账单为准”。配送、推广、活动支出没有适用所有门店的统一固定比例，本次不编造平均值。

### 信息图建议：不是佣金饼图，而是老板的订单账本

建议画五段瀑布/收支图，金额可不填，或仅用明确标为“演示算账”的假设金额：

**门店确认的订单收入 → 技术服务费 → 配送费 → 自愿推广投入 → 商家承担的活动优惠 → 经营贡献**

另在备注写清：这是核算结构示意，真实账本应按门店结算口径避免重复扣减；还需计入食材、包材、人工、房租等成本。不能拿未扣经营成本的结余称净利润。

若使用返佣词，必须具体分辨是平台向商户退还佣金/费率优惠，还是美团联盟向推广者付佣。二者完全不同。本次未获得适用所有餐饮门店的统一“返佣比例”，不展示数字。

### 2026现状：可用一条事实，马上返回产品

2026-06-17，市场监管总局发布《外卖平台补贴行为规范十条（征求意见稿）》说明，指出外卖行业“拼补贴、拼价格、控流量”问题，并拟明确不得强制商家参加补贴或承担补贴成本。**此来源是征求意见稿，不能讲成已正式施行的新法。**[市场监管总局公告说明](https://www.samr.gov.cn/zt/ndzt/2025n/zhzznjsjzwhgpjzsczx/zjbs/art/2026/art_5a4d1c0322b14c25a15399a0b2fe3c8f.html)

2026-07-07总局新闻发布会中，北京市市场监管局介绍了推动佣金让利、削减大额补贴等治理举措。仅代表该次发布会的监管方向，不能转成成都所有门店已获返佣的事实。[总局新闻发布会实录](https://www.samr.gov.cn/xw/xwfbt/art/2026/art_3d37efec03df4181bdfb0e02b40e9204.html)

截至本次检索，最新美团2026-08-28二季报官方说明称竞争趋于理性、经营利润环比转正。不要沿用2025年“仍在无限烧钱、补贴只会越来越大”的旧叙事。[美团2026年二季报](https://www.meituan.com/news/NN260828216013035)

### 可上屏的强销售文案

> **让美团成为一个渠道，让生意有更多入口。**
>
> **把获客、内容和复购的主动权，拿回自己手里。**

讲稿：“平台能带来订单，但老板要同时拥有让顾客记住店名、主动搜索、愿意再来的能力。小红书种草、短视频、店长复盘和会员触达，过去需要几个人接力，现在我们把这支数字员工队伍交到老板手里。”

这保留用户想表达的独立经营、降低单一渠道依赖的力度，同时避免把撤离平台当作无条件经营建议。主会场最多1页现状，立即返回纳米产品和案例。

## 4. 360 / 纳米Work：能讲哪些品牌与安全事实

### 可证实

- 360社区管理员2026-08-14公告称360集团发布新一代智能体工作平台纳米Work，给出官方入口work.n.cn。[360社区版块升级公告](https://bbs.360.cn/thread-16184891-1-1.html)
- 纳米Work官方隐私政策实际页面更新/生效日为**2026-07-21**（搜索摘要仍显示旧日期6月23日，以已打开正文为准），提供者为天津智炬科技有限公司，文中简称“360”。政策写明境内收集和产生的个人信息境内存储，对可识别个人身份信息采用加密传输和存储，提供个人信息管理路径。[纳米Work隐私政策](https://work.n.cn/agreement/aprivacy.html)
- 2026-08-21，360安全应急响应中心把纳米work网页、移动端、PC端列入漏洞响应活动范围。可支持“纳入360安全响应体系”，不能据此声称零漏洞或通过某项未验证认证。[360SRC官方活动](https://security.360.cn/News/news/id/375)
- 开发者在中国区App Store将纳米Work描述为“360出品的AI工作平台”，并介绍AI指令防护、文件保护等能力。[纳米Work中国区App Store](https://apps.apple.com/cn/app/%E7%BA%B3%E7%B1%B3work/id6777950766)（页面无产品介绍发布日期；2026-09-05访问）
- 纳米AI搜索的360官方报道可支持搜索、内容创作技术积累，但其历史榜单及能力不能自动等同于这份行业版的全部功能。[360官方：纳米AI搜索鸿蒙原生版](https://news.safe.360.cn/n/12656.html)（2025-02-21）

### 对老板说人话的安全页

建议标题：**“老板敢交工作，先要看清数据怎么管。”**

三个可呈现模块：**360产品体系 / 个人信息加密与境内存储 / 权限和任务记录有据可查**。第三项必须与行业版的实机功能对应，不能拿个人信息政策推导所有商业文件均有专属权限隔离。

演讲备注：“底座来自360，实际业务中仍按授权接入数据、按权限执行操作。具体部署与模型/API数据处理，以交付版本、第三方服务和合同条款为准。”

### 必须留在编辑审核里的边界

官方政策明确会收集用户输入以提供AI服务、在法定时间保留历史任务，并自动上传产出到云盘。因此**不能写‘数据永不出本机’‘从不上传任何数据’‘任何资料绝不泄漏’‘所有模型都不用数据训练’**。本地行业版如果采用自定义API，更应逐项核实实际路径。

“纳米Work是360产品”有公开佐证；用户另已明确确认本地行业版为360官方产品，可按其内部事实使用。数字岗位方法来自演讲者本人10年企业培训、3年企业转型经验，不扩写成每个数字员工均由不同真人一对一复刻、不扩写成360自有培训履历或独家私有数据库。

## 6. 交给PPT制作的执行建议

- 产品与案例占主体；平台现状1页、竞品QA1至2页即可。
- 竞品比价：呈现收费结构与公开样例价，不计算“我们省X%”，不展示尚未确定的纳米销售价。
- 对纳米的定价悬念：比较“招聘一个内容运营、一个选址分析、一个经营助理，需要什么年度预算”，随后问“如果把这些岗位能力组成一支数字团队，您愿意给它多少预算？”人员工资另需招聘数据或明确假设，不能把数字员工数量直接乘以真人全职年薪称已实现节省。
- “真人经验”页展示实际来源、经验沉淀流程、技能库和成品，不用“其他产品都是Excel提示词”这种无证据判断。
- “搜索强”用有来源链接的真实商圈/竞品分析产出展示；不承诺拥有美团后台数据或未经授权的非公开商业数据。
- 所有“案例”分清真实客户结果、真实产品操作演示、设定情境演示；没有成交/营收证明的案例不宣称经营增长。
- 9月9日上场前重新打开两个价格页/合同页复核，避免价格变动。主要公开证据已在以上各段就近链接。
